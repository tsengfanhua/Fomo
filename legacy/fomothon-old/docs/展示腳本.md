# 決賽展示腳本（5 分鐘）＋答詢準備

決賽規則：每隊 9 分鐘，5 分鐘 Demo／簡報，4 分鐘 Q&A（評審統問 1 分鐘、團隊統答 3 分鐘）。主辦單位不支援現場切換設備，報告用的檔案由主辦單位從競賽平台下載。

**這版腳本以技術為主軸**：MCP、多模型路由、資料品質與評測，網頁畫面只用來看執行紀錄。建議全部先錄成影片放進簡報，現場不依賴網路與設備切換。

## 答詢準備

回答時請以實際狀況為準，不要把還沒做的事說成已經做了。

### MCP

**為什麼要做 MCP？用網頁不夠嗎？**
學生不一定會打開我們的網頁，但會用 AI 助理。MCP 是 AI 助理呼叫外部工具的開放標準，做成 MCP 伺服器後，Claude、IDE 或學校其他系統都能用同一個介面使用我們的 Agent 與 Skill 資料庫，不用各自串接。

**為什麼自己實作協定層，不用官方 SDK？**
為了維持執行期零相依（校園部署的供應鏈風險低、一行指令就能啟動）。自己實作的風險是「自以為相容」，所以我們用官方 SDK 的 client 做互通測試，stdio 與 HTTP 兩種傳輸、11 個工具都通過它的輸出驗證，也用 MCP Inspector 檢查過。

**外部 AI 會不會亂發邀請、看到別人成績？**
不會。MCP 工具全部唯讀，送出邀請仍要學生在系統內確認；每個連線綁定一個帳號，只讀得到那個帳號在網頁上看得到的資料；輸出不含成績與精確分數，這點有自動化測試逐一檢查欄位。

**HTTP 版本安全嗎？**
預設關閉。開啟後每個請求都要個人權杖（只存雜湊、有期限、可撤銷），也檢查來源防 DNS rebinding。要老實說明的是：MCP 規範建議用 OAuth 2.1，我們目前是個人權杖，要讓雲端 AI 平台直接連線還要補 OAuth 與 HTTPS。

### 多模型

**為什麼不全部用最強的模型？**
不同任務需要的能力不同。任務辨識是分類，小模型就夠；萃取要理解語意。我們用檢核決定是否升級：小模型的輸出沒通過系統原本的檢核才換大模型，正確性的底線由檢核保證，不是由模型保證。

**各模型實際表現如何？**
評比工具已完成：錄下系統實際送出的 73 個請求，對每個模型重播並用同一套檢核計分。【若決賽前已執行，在此填入 `MODELS.md` 的結果；若沒有，如實回答「還沒有真實模型的數字」】

**個資會不會送到雲端模型？**
成績從來不送。送往雲端前，路由器會自動遮蔽 Email、電話、身分證字號、學號；建議說明中的人名換成代號，回到本機才換回。學校若希望資料完全不離開校園，可以改用 `local` 路由接校內的地端模型（例如 Ollama 上的開源模型或 TAIDE）。

**LLM 會不會亂給分數？**
分數與資格全部由固定規則計算。LLM 只做任務辨識、課綱語意萃取、在合法動作清單內選下一步、潤飾說明四件事，每一件都要通過檢核，全部模型都失敗就退回規則。

### 資料品質

**資料品質分數怎麼算？**
23 條規則分 6 個面向（完整性、有效性、唯一性、一致性、時效性、可信度）。每條規則的通過率是合格筆數除以檢查筆數，面向分數是加權平均（error 權重 3、warning 權重 1）。任何 error 等級的問題都會讓系統拒絕建庫。

**99.1 分是不是自己給自己打分？**
規則是我們訂的，但它真的抓到過系統錯誤（「JS」誤中「Node.js」），也誠實列出還沒解決的問題（Git 沒有外部標準對應）。分數反映的是這份合成資料，接真實校務資料後要重跑。

**標準答案是 AI 標的，可信嗎？**
這是預標註。兩位標註者是不同模型、彼此看不到對方、也看不到我們的萃取規則，一致性 κ 0.944；分歧的項目不計分，不由知道萃取結果的人裁決。正式評測前要請兩位教師複核，再用同一支程式重算。

**萃取 F1 82.3% 夠好嗎？**
主要的錯誤是 Precision：程式語言只當工具使用的課也被標成教該語言。這正是 LLM 萃取要補強的地方，也是多模型評比要量的數字。

### 其他

**為什麼需要 Agent，不用固定流程？**
參賽準備的每一步都取決於上一步的結果：有沒有缺口決定要不要找隊友，資格不符就得換競賽，第一輪找不到人要擴大搜尋。評測裡把這些機制關掉的固定工作流，在 19 個案例中只完成 12 個。

**場域驗證做到哪裡？**
【待團隊依實際情況回答】目前系統只用合成資料驗證。初賽做了 26 份問卷與訪談（Level 1）。若決賽前有真實學生或教師試用，請在這裡補上人數、做法與回饋。

**資料是真的嗎？**
展示用的人物、課程、競賽與成績都是合成資料。課綱爬蟲抓的是系統內建的示意課綱站；接真實的課綱系統需要另寫頁面解析，也需要取得授權。

**成本與部署？**
離線模式的模型成本是零，一行指令就能啟動，執行期沒有外部相依套件。地端模型的邊際成本也是零。雲端模型的實際成本要等多模型評比跑完才有數字。正式上線還需要真實登入、HTTPS、資料刪除機制與備份。
