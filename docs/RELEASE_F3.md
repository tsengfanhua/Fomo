# FomoThon F3 — 媒合隱私與資料可信度

## 本版變更

- 媒合搜尋只使用已開放媒合、每週可投入時數大於零、能力檔案已確認且未過期的學生。
- 精準搜尋、證據補查、潛力探索共用同一資格閘門。
- 邀請寫入前重新驗證對象資格，避免同意狀態改變後仍送出邀請。
- 競賽補位覆蓋率採用相同資格條件。
- 搜尋事件增加未確認／過期檔案排除數量。
- 新增媒合同意閘門回歸測試與設計文件。

## 驗證

- Node test suite：106 tests，103 passed、0 failed、3 skipped。
- Data quality：99.1/100，閘門通過。
- Anonymity scan：99 個檔案，0 個禁用字串命中（未提供本機 denylist）。

## 相容性說明

本版沿用既有 SQLite schema，不需要新增資料表或資料庫遷移。未確認或過期的學生會從媒合結果中排除；因此推薦數量可能低於舊版，這是刻意的隱私保護行為。
